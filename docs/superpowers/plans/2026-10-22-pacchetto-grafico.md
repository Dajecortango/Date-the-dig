# Pacchetto grafico (punti 5, 6, 11, 14, 15, 21-23, 25-28, 31-35) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the scene more life and direction without changing the art style: sprite lighting (speaker and location), emotional micro-movements, depth of field, new particles, a richer textbox, choices, calendar, day card, Borsa, main menu, a transition vocabulary, camera moves and thought lines.

**Architecture:** Pure rules go in a new `game/regia_logic.py`, tested by `tests/test_regia.py`. One new file, `game/luce.rpy`, redefines every sprite and background image as `At(file, <transform with function>)`. That transform does the tint, the speaker dimming, the expression movements and the background blur, so no `show` line has to change and positions stay intact. Camera, blur and transitions are small helpers in `regia.rpy`. The UI items are local edits to the screens that already exist. Assets are generated by `make_gui.py` and `make_audio.py`.

**Tech Stack:** Ren'Py 8.3.7 (`tools/renpy-8.3.7-sdk`), Python 3 (`py -3`, with PIL and numpy) for the tests and the asset scripts, `lint.ps1`.

**Spec:** `docs/superpowers/specs/2026-10-22-pacchetto-grafico-design.md`. Read it before any task. Section letters (A–J) refer to it.

## Global Constraints

- No `git commit` and no `push` unless the user asks (user rule). "Checkpoint" means: run the tests and the lint, then stop. Do not commit.
- With `mm_movimento_ridotto()` True, every effect in this package is static or instant: no movement, zoom, cascade or camera. Tints, outlines and colours stay.
- Do not change the art: no new backgrounds, sprites, expressions, CGs, `layeredimage` or name seals.
- Scene text does not change. Route edits may only add or change `with` and `scene` transitions, `$ camera_*()` / `$ intimo()` calls, and the speaker of narration lines (`pensiero`).
- Visual state that is not story state goes in `NoRollback` objects, as in `effetti.rpy` and `feedback.rpy`. Story-facing flags (`regia_intimo`) are `default` variables, so rollback and load restore them.
- Android (`renpy.variant("small")`): no extra per-frame work beyond what each task states. Cap particle counts at the current levels.
- Every task ends with all `tests/test_*.py` green and `lint.ps1` clean.

Run all tests (repo root, Git Bash):
```bash
for f in tests/test_*.py; do py -3 -I "$f" > /dev/null || echo "FAIL $f"; done
```
Expected output: nothing. Lint: `powershell -File lint.ps1`. Expected: a report with no errors.

## Review Focus

1. **Rollback or load in the middle of a camera zoom or blur.** The camera must be at rest and the blur must match `regia_intimo` after the load. Owner: Task 9 (camera reset in `config.after_load_callbacks` and in the scene hook; test greps for both).
2. **A sprite shown at `left`/`right` that changes to `sorpresa`.** It must move and then return to the same place. Owner: Task 2. The movement lives inside the image `At()`, never in the `at` list. Manual check in Task 12.
3. **Skip mode (Ctrl) and auto-forward.** No movement starts, cascades are skipped, and the day card still passes in 0.05 s. Owner: Tasks 2, 4, 5 (`renpy.is_skipping()` guard; listed in each task).
4. **A narrator line converted to `pensiero` that contained a menu caption or a `centered` line.** That would break menus. Owner: Task 11 (the conversion regex only matches bare `"..."` lines with no trailing `:`; the test greps for `pensiero "...":`).
5. **Images with no matching file after the redefinition loop**, for example a typo'd tag or the `bg nero` colour image. Lint must not report undefined images. Owner: Task 2 (the loop only wraps files that exist; lint is the gate).

- `movimento_per(vecchia: str | None, nuova: str) -> str | None`. Returns `None` when `vecchia is None` (first entrance) or `vecchia == nuova`.
- `MOVIMENTO_PAUSA = 3` (interactions before the same sprite can move again)
- `piove(luna: int, giorno: int) -> bool`. Returns `(luna * 31 + giorno * 7) % 3 == 0`.
- `transizione_scene(bg_prec: str | None, bg_nuovo: str, trans: str) -> str | None`. Gives the replacement for one `scene ... with trans` line, or `None` to keep it. Rules: `bg_nuovo == "nero"` → `None`. `trans` not in `("fade", "dissolve")` → `None`. `bg_prec is None or bg_prec != bg_nuovo` → `"stacco"`. Otherwise → `"salto_tempo"`.
- `FONDI_ROUTE = {"Aede": "cala_notte", "Caino": "corridoio_ceppo", "Druso": "palestra", "Icaro": "vicoli_zefiro", "Ofelia": "consiglio"}`
- `fondo_menu(ultimo: str | None, finali: list[tuple]) -> tuple[str | None, str | None]`. Takes a `FINALI` row `(id, titolo, route, indizio)`. Returns `(bg, chiave_cast)`, where `chiave_cast` is the route name in lower case. `finale_neutro_semestre` → `("esterno_neve", None)`. `None` or an unknown id → `(None, None)`.
- `conteggio(da: int, a: int, t: float, durata: float = 0.6) -> int`. Integer ease-out from `da` to `a`. Returns `a` when `t >= durata`.

- Produces: `luce_personaggio(tag: str) -> Transform` and `fondo_fx() -> Transform` (the second is used by Task 9). Behaviour of the function in `luce_personaggio`:
- The tint comes from `tinta_per(bg attribute on master, store.cal_slot)`. The brightness target is `LUCE_OSCURATA` when `oscurato(tag, renpy.get_say_image_tag(), sprite tags showing on master except "bg")` is true, otherwise 1.0. Brightness eases toward the target over 0.2 s (instant with reduced motion). The `matrixcolor` is the tint blend `TINTA_FORZA` times `BrightnessMatrix`.
- Movement: the function compares `renpy.get_attributes(tag)` with the last value it saw for that tag. A change for which `movimento_per` returns a name starts that movement. It does not start when skipping, with reduced motion, or within `MOVIMENTO_PAUSA` interactions of the last movement for that tag. Count interactions with a `config.start_interact_callbacks` entry. Movement curves, about 0.35 s each: `sobbalzo` yoffset 0→-18→0; `arretra` zoom 1→0.97, yoffset +6, then back; `avanza` zoom 1→1.03, then back.
- Keep per-tag state in one `NoRollback` object. Reset it in `config.after_load_callbacks` and when `store.main_menu` is true.
